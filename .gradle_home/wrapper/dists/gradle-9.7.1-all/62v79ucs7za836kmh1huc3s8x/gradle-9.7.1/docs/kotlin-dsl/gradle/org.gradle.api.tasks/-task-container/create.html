abstract fun create(options: Map<String, out Any>): Task(source)

Deprecated

Use register or register instead. See documentation for more information.

Creates a Task and adds it to this container. A map of creation options can be passed to this method to control how the task is created. The following options are available:

{@value Task#TASK_NAME}The name of the task to create.None. Must be specified.
{@value Task#TASK_TYPE}The class of the task to create.org.gradle.api.DefaultTask
{@value Task#TASK_ACTION}The closure or Action to execute when the task executes. See doFirst.null
{@value Task#TASK_OVERWRITE}Replace an existing task?false
{@value Task#TASK_DEPENDS_ON}The dependencies of the task. See here for more details.[]
{@value Task#TASK_GROUP}The group of the task.null
{@value Task#TASK_DESCRIPTION}The description of the task.null
{@value Task#TASK_CONSTRUCTOR_ARGS}The arguments to pass to the task class constructor.null

After the task is added, it is made available as a property of the project, so that you can reference the task by name in your build file.

If a task with the given name already exists in this container and the {@value Task#TASK_OVERWRITE} option is not set to true, an exception is thrown.

Return

The newly created task object

Parameters

options

The task creation options.
